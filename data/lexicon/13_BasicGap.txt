# 真题高频但原词库漏收的词
#
# 来源：output/未收录高频词.txt 里出现 ≥3 次的词，排除功能词（the/and/that）、
# 题干套话（mainly/passage/exams/directions）和人名（skillman/ventura）之后剩下的实词。
# 屈折形式统一折回原形收录（designers→designer、built→build），
# 词形由 core/lexicon.py 的规则自动还原，不需要为每个变形单独建条。
#
# 为什么单独成一册：这些词大多是最基础的高频词，而原分册 01-05 收的是"稍难的核心词"，
# 反而把 eat / sell / pay / talk / save 这类真正常出现的基础词漏掉了。
# 格式同上：单词|词性|义项(分号分隔，带*者为常考义)|等级(A基础/B核心/C进阶)|搭配提示
